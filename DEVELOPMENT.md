This is a new portfolio reference implementation built with AI assistance. Its Git history records the actual implementation work; it is not a history of commercial deployment.

Sample companies, records, documents, and tasks are synthetic. Checked-in measurements come from the scripts in this repository. Simulator scores and tiny-model experiments are not evidence of performance on real financial workflows. External model adapters require separate validation with the configured provider.

Before presenting the project, run the demo and tests, read the design notes, reproduce the measurements, and practice making a small change without assistance. The README identifies what was exercised and what remains an extension.

Release 0.2 adds complete browser workflows and larger measured studies. Public-data experiments use the cited SciFact and BANKING77 sources where applicable; these are distinguished from fictional operations scenarios. The repositories retain failed experiments and disclose the limits of local measurements.
